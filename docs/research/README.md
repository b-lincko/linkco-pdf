# Product research

## PDF product strategy — 25 October 2026

**[Read the strategy and prioritized feature plan](pdf-product-strategy-2026-10-25/README.md).**

The study covers Linkco PDF desktop, web, CLI/MCP and OS/storage integrations. Native mobile and a collaboration service are labelled proposed surfaces. It includes 222 recommendations, all 384 partial/planned checklist entries, an 833-feature baseline and 29 external sources.

A filterable [Excel workbook](pdf-product-strategy-2026-10-25/Linkco-PDF-Product-Strategy.xlsx) and CSV exports accompany the report. Research is documentation, not a claim that features have shipped or passed new runtime acceptance tests.

The dated baseline is intentionally immutable. See the report for generation instructions, limitations, priorities, sharing design, and the proposed validation programme.
